# Explicit diagram playback — 2026-09-10

The V2 host deliberately starts readers in Still. The native Play button previously used the automatic-playback gate, so it was disabled while the separate host button could resume Live. This caused the reported dead control.

Native Play now resumes Live for the current viewing session and starts the existing story. It does not change the saved motion preference. Pause, progression, chapter controls, hidden-tab suspension, print and system reduced-motion behavior remain in the existing reader. Automatic share playback retains its original gate.
