# E operational UI — approved direction applied

Huashu-Design prototype guidance is applied to this existing approved product, not used to reopen the design direction. User-authorised stack and black/blue/white theme override new React, decorative assets or exploratory variants. No client brand identity is inferred from the earlier Macquarie visual reference.

## Form derived from the work

- **Narrative role:** Clearance answers “what remains, who acts next, and may this scope be confirmed?” QA detail answers “which evidence use failed, what was supplied, and has QA actually re-reviewed it?”
- **Viewing distance:** laptop operation first, workshop screen second, responsive mobile fallback. Primary copy at least 14px; labels/annotations at least 12px. Compact graph context must have larger semantic text alongside it.
- **Temperature:** quiet and authoritative. Existing neutral panels and restrained blue actions; no mint/violet, heavy glow or invented brand assets.
- **Capacity:** six condition groups with concise summaries; details expand by relevance. Separate review form and one intentional commit action from read-only story steps. Never expose seventeen equally prominent command buttons as the main interface.
- **Content-led form:** the condition-to-prerequisite relationship and exact purpose-specific QA chain provide the structure. No fabricated metrics, progress percentages, decorative stats or generic explanatory hero.

Use established fonts, spacing, pill controls and glass interactions. Keep text and icons stable; glass is a backdrop-blur/highlight approximation, not an optical-refraction claim. Idle stays still; reduced-motion behaviour and disabled/focus states inherit the existing system.

Verify real browser interactions, console errors, English/Chinese content, desktop/narrow sizes and complete print. Root inspects screenshots after implementation; test pass is not user visual acceptance. This note is an assumption record for the incremental application of an already approved direction, not a new design approval request.
