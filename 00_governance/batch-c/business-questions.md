# Batch C open business questions and reserved interfaces

These are not implementation defects or bank policy. Source: SRC-016 Final1.0, S-USER-C. Bank/control owners remain unassigned; no authority is inferred from this register.

| Question | Current demo boundary | Required confirmation / next-group interface |
|---|---|---|
| C-Q-POPULATION | A/T are explicitly included for a named synthetic preliminary context; B membership unresolved; ownership/control item remains open | Applicable subjects/categories, inclusion/exclusion bases and full inventory confirmation authority |
| C-Q-DATASET | Synthetic dataset/version/as-of and retrieval times only | Permitted actual sources, programme/list coverage and reuse/currency criteria; no live provider integration |
| C-Q-IDENTITY | EV-ID-C01 exists only after a real synthetic submission event; insufficient/unknown uses are runnable | Separately reviewed identity package, sufficiency rationale and independent oracle before enabling exclusion |
| C-Q-DISPOSITION | Record-disposition stays disabled_pending_fixture_review even for simulated Financial Crime role | Scoped reviewer authority, required independent approval and evidence rule; changing role is not authentication |
| C-Q-REFERRAL | Can record concern and next work while evidence is missing; default owner Unassigned | Named target queue, assignment and valid return/review event before substantive resume |
| C-Q-HOLD | Unknown relevant Hold blocks the affected action; no blanket assertion that unrelated work is free | Hold scope, affected objects/actions, owner and release criteria |
| C-Q-EDD-APPLICABILITY | Default unknown; empty reviewed-reason registry | Independent current reason, basis, scope and applicability decision authority; never every alert automatically |
| C-Q-EDD-APPROVAL | Limited pack interface, no approval writer or fabricated completion | Specialist assessment, targeted evidence and approval/condition rules; no universal SoF/SoW requirement |
| C-Q-COLLABORATION | Existing B request/grant/auth/intake contract reused with separate identity request; local synthetic adapters only | Real disclosure, contact, identity, access and communication policies; no actual client messaging |
| C-Q-RESEARCH | Inherited source observations, not fresh regulatory or link verification;19assets not captured | External-link/current excerpt checks and asset rights before any external release; no internal originals in shareable source layer |
| C-Q-LAB | Same-revision read-only lenses and disabled single evidence-use inject interface | Independent approval before enabling the one shadow inject; no automatic mainline write-back |
| C-Q-NEXT-GROUP | Legal/Credit/QA/Conflicts and publication conditions retain their existing statuses | Later approved groups supply real synthetic task and clearance contracts; C does not complete all D2 |

The old Entity A possible-match fixture is retained as historical legacy content. The C slice selects its own Person T finding by immutable run/subject references; never repurpose the old ID or reducer.
