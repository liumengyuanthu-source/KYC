# 目标旅程交互画布

完整旅程页面已采用 CTT_Target_Process_Redraw.svg 的实际流程内容，交互界面来自 ref flow/maka-regenerated.workflow.html。配色适配为 NTT 风格的深蓝、蓝色与白色；保留 Clear to Trade 名称。

## 内容与使用

- 保留原 SVG 的 31 个节点、31 条连接、M0–M8 阶段、人工判断、法务／信贷并行工作与整体就绪条件。
- 顶部五个阶段分别聚焦发起、确定要求、评估、解决问题、确认就绪；解决问题包含法务、信贷和利益冲突节点。
- 可使用参考 HTML 提供的缩放、平移、节点查找、关系聚焦、路径追踪、引导演示及导出工具。
- 先选择节点，再点击“打开场景详情”进入已有场景；关闭详情后返回旅程。场景中的目标流程编辑与本地保存入口继续保留。
- 总览采用提供的 SVG，场景详情沿用已有场景资料；编辑场景流程不会自动改写总览 SVG。
- 中英文随页面语言参数切换，业务编号保持不变。

## 来源关系

HTML 提供交互与布局机制；SVG 提供业务节点和连接；现有场景数据提供明细和编辑能力。参考 HTML 原有 Maka 内容已移除。

节点到场景的连接为导航映射，例如一次采集 → SCOPE、复用证据 → SOURCE、筛查与准备 → POPULATION、人工筛查判断 → MATCH、就绪状态 → READINESS；它不表示原场景明细已由 SVG 重新生成。

## 验证

逐项比对原 SVG 与新画布中的节点 ID、连接起点与终点：顺序与数量一致。浏览器验证节点查找、聚焦和 SCOPE 详情打开成功，详情保留目标流程编辑按钮。英文和中文页面均完成加载检查。
