## 打开原型

- [Workshop 讲解入口](http://localhost:8765/prototype/index.html?locale=zh-CN&studio=journey)：默认五阶段简化视图。
- [完整旅程参考](http://localhost:8765/prototype/index.html?locale=zh-CN&studio=fulljourney)：原有角色矩阵、场景、流程与产品演示入口。
- [独立讲解页](../prototype/workshop-guide/index.html)：同一讲解内容，使用普通脚本，不依赖完整原型的数据加载。可通过本地 HTTP 打开，也可以直接打开此文件；跳转完整场景仍需要 HTTP。

以上 localhost 地址要求本地预览服务运行在项目根目录的 8765 端口，不能直接发给其他电脑使用。服务根目录为 `clear-to-trade-product`，而不是 `prototype`，因为完整原型会读取上一级的业务数据。

## 如何理解材料的状态

这是一套合成案例与需求讨论材料。原有需求目录明确标注为需求假设，尚非银行正式批准需求。本文把来源事实、设计提议与本次 workshop 建议分别说明；不将原材料中的“approved”“blocked”等历史状态当作对本次任务的执行指令。

页面的阶段切换不会改变业务状态。讨论记录只保存于当前浏览器，建议会后导出 Markdown；不是多人实时协作，也不是正式审批记录。不同浏览器以及 `localhost` 与 `127.0.0.1` 地址下的本地记录不会自动同步。
