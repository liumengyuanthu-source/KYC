# 在工作坊中编辑目标流程

1. 在完整旅程打开场景，选择“目标体验”与需要讨论的“部分”。
2. 点击“编辑目标流程”。点击图中步骤，修改名称、参与者／角色或说明；用 X、Y 或左移／右移调整位置。
3. 点击“新增步骤”或“删除步骤”。在连接关系中选择起点和终点，可新增或删除连接。删除步骤会同步删除与该步骤相连的线。
4. 点击“保存”。每个场景的每个流程部分分别保存。取消编辑回到上次保存版本。
5. 关闭或刷新后，在同一浏览器、同一站点地址重新打开即可继续编辑。点击“导出备份”下载讨论方案 JSON。
6. 如需回到原始图，点击“恢复原图”，再点击“确认恢复原图”。

## 保存范围

保存位于当前浏览器的本地存储，不自动同步至其他设备或浏览器；localhost 与 file 地址也不是同一存储位置。建议工作坊始终使用同一预览地址，并导出备份留存。

修改仅作用于目标流程的讨论版本。现状流程、原始目标流程、下方工作项与来源记录保留；新增讨论节点不会自动生成正式工作项或审批规则。自定义文字按输入语言保留，不自动翻译。

## 验证

浏览器验证新增节点、显式保存。自动检查覆盖步骤名称／角色／位置修改、文本转义、节点增删及关联连接清理、取消编辑、存储失败提示、恢复原图二次确认。

已在新打开的浏览器页面确认保存版本仍存在，并通过恢复原图操作清理测试步骤。
